\begin{abstract}
The Bandwidth Minimization Problem (BMP) is a classic NP-Hard problem in graph theory, with various useful applications - such as in sparse linear system solving, circuit designing, and network simulation. This report presents an approach to solving the BMP, as the Boolean Satisfiability (SAT) problem. We evaluated two encoding techniques (Order Encoding and Pairwise Encoding), combined with two SAT solver strategies (Repeated SAT and Incremental SAT). Empirical demonstration on the standard Harwell-Boeing benchmark dataset demonstrate that the Order Encoding paired with Incremental SAT achieves superior efficiency, substantially reducing execution time near the optimal bounds. Moreover, we will compare various methods outside SAT to approach the problem, in particular, Integer Linear Programming (ILP) and Constraint Satisfaction problem (CP).
\end{abstract}
